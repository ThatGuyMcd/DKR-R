DKR-R v1.0.9 - Detail Playtest 4

This replaces Detail Playtest 3. Extract it into a fresh folder, and make sure
everyone in the online lobby is using this same build.

What changed

The custom car picker drawing fix is kept. Your latest log confirms its private
online drawing path is active. The new stop happens afterwards, when starting
the race. The confirmed race loader hit its fixed 40-million-operation limit
while creating racer attachment textures. That allowance was shared by the
whole scene load, including all racers, models, LODs, animations and textures.

Confirmed scene loading now has a separate 256-million-operation allowance.
It is still bounded. The menu/background allowance remains 40 million, and
normal race ticks remain at 5 million. This does not increase the amount of
work run every frame or force different graphics settings. No content is
silently disabled, no models are downgraded and no save data is rewritten.

Guest memory validation, allocator index/traversal checks, native callback
fences, confirmed-only scene admission, GPU draining and save journals are
unchanged. A broken allocator list still stops through its existing guards.
The loader now logs its budget, actual work and elapsed time on success or
failure, so a remaining failure is easier to identify. Both US ROM revisions
and Windows/Linux share the same new online compatibility policy.

What to check

[ ] Repeat the exact same lobby, mods, track, characters, cars and CPU count.
[ ] The vehicle picker is visible, left/right works and both players can ready.
[ ] Start the race: it gets past scene preparation and all racers appear.
[ ] Complete a race, retry, change tracks and return to Track Select.
[ ] If convenient, repeat with eight racers and different custom characters.

If it stops again, close DKR-R normally and send runtime.log from both PCs.
Look for [rollback][scene-work], which records the exact loading work used.

Windows x64 and Linux x86_64 AppImage. Compiled and statically inspected only;
the game, mods, test executables and AppImage were not launched. Your exact
modded session still needs gameplay confirmation from you. No ROMs, saves or
personal settings ship here. This is not a signed automatic-update release.
