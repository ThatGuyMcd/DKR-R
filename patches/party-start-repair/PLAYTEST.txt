DKR-R 1.0.9 - Online start repair playtest 10
===========================================

Use this complete fresh package on EVERY PC in the lobby. Do not mix playtests
or copy only the executable into an older installation. Existing saves and
installed content stay where they are. The game has not been launched here.

The five-second countdown is back in spectator-capable lobbies. Start now
validates every required racing route, the roster, settings and verified online
save. Each racer acknowledges the prepared grid and committed launch before
the host leaves the lobby. A changed lobby or missing acknowledgement cancels
the start safely, with a reason, rather than silently launching only the host.
Spectators still have no controller port and do not block the racing barrier.

Fresh racers use the existing canonical zero-frame owned-checkpoint admission
gate. Future spectator checkpoints retain their separate confirmed-state
admission and irreversible save/Pak/action validation. Checkpoint offers and
Ready/Go control messages have bounded, idempotent retry handling. Initial
capture/compression no longer retains the transport's party lock. Logs now
identify boot, capture, encoding, transfer, admission and release stages, and
record the real runtime error instead of losing it behind a generic wait.

The original lobby design, spectators, player swaps, invites, mod admission and
Rollback connection check are retained. No graphics renderer, game physics,
mod package, personal save or checked-out dependency was changed.

CHECK DURING YOUR PLAYTEST
1. Start with two racers ready. Both should see five seconds counting down.
2. Both should reach the game, character select and track select, then race.
3. Repeat with spectator capability disabled, and with three/four racers.
4. Join a spectator, switch viewing modes, and try a safe racing-place swap.
5. Return to the lobby and start again. Cancelling Ready or changing the lobby
   during countdown should cancel it, not launch a partial group.
6. Try the Rollback connection check while waiting in the lobby.

If it still stops, close normally and retain runtime.log from BOTH host and
client. The new [lobby][start-*] and [party][*] entries identify the actual stage.
Compilation/linking and static source/binary/archive checks only were performed.
Gameplay and real-network acceptance remain yours. Nothing was pushed,
published or signed for automatic updating.
