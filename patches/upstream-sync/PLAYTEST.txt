DKR-R v1.0.9 - Spectators Playtest 7
Upstream sync, with the current features kept intact.

This build includes the recently merged GitHub PRs #66, #67, #68 and #69.
The local game patch layers have also been checkpointed in Git, so they no
longer exist only as untracked files on this PC.

The important player-facing fixes here are:

- Track imports reject unsafe manifest IDs before using them as folder names.
- Replacing a track stages the new copy first and restores the old installation
  if replacement fails, rather than deleting the installed track up front.
- The graphics preset dropdown follows the saved settings. Manually tuned
  settings show Custom instead of looking as though Balanced was reapplied.
- The frozen build sources receive the matching upstream compatibility fixes;
  these are not just changes sitting unused elsewhere in the repository.

The original restored lobby, spectators, live player swaps, invitations,
Rollback-only defaults, Store Vehicles, custom vehicles, seating and wheel
interpolation, all-view detail work, achievements, texture dumping and previous
water/save fixes are retained. No gameplay, renderer or network algorithm was
replaced as part of this sync. Mac/iOS source improvements are preserved, but
this package set is Windows x64 and Linux x86_64 AppImage only.

Please use this same build on every participant in a playtest lobby. Earlier
packages have been kept. Extract the Windows ZIP into a fresh folder; on Linux,
make the AppImage executable and launch it normally. Supply your own supported
DKR ROM. No ROM, user save, profile, private key or optional installed mod ships.

I have compiled the builds and checked the source, linked features, retained
contracts and packages. I have not launched the game, mods, test executables or
AppImage. Gameplay and hardware acceptance remain yours. Please check importing
and replacing tracks, saved/custom graphics presets, the restored lobby and a
normal online session before treating this as a fully playtested release.

This is an unpublished playtest, not a signed automatic update or public release.
