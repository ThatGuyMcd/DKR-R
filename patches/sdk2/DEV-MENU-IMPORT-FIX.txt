DKR-R DEV MENU 2.0.1 - BETA 7 IMPORT FIX

Import DKR-R-Dev-Menu-2.0.1.nrm from MODS / HACKS, then approve and enable it.
Keep your current v1.0.7 beta 7 app. This fixes the mod package, not the app.
If an older Dev Menu is listed, use the new edition rather than enabling both.
For online development, everyone needs the same corrected mod edition.

The original package contained incomplete MIPS relocation targets. Some split
addresses referred outside their declared section, so the importer correctly
stopped installation. Its pointer/jump-table targets also lost their addends.
This was a build-tool/package problem, not your installation or save files.

The corrected SDK keeps each data item in a separate ELF section, disables
machine-level common-address merging, derives complete local targets from the
linked ELF and checks address carries at arbitrary 16-byte-aligned mod bases.
It also mirrors the app's complete symbol-table bounds checks before creating
the final .nrm. Ambiguous addresses stop the build instead of being guessed.
SDK2-RELOCATION-REPORT.json records each correction in this Dev Menu build.

No game-loader guard, memory permission, API, SDK header, application binary
or online engine identity has changed. Existing installed mods are untouched.
The SDK ZIP contains the corrected builder, Dev Menu source and compiled mod.
The previous TXT/HTML/PDF Bible is retained; the public APIs are unchanged.

Compilation and static package/address inspection only. No game, mod,
unit/replay test, multiplayer session or headset was run by the agent.
Gameplay and performance acceptance remain with the user.
