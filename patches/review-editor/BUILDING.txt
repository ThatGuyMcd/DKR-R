DKR-R v1.0.9 development - Review editor
======================================

The selected star rating now uses the same yellow buttons as the Store tabs.
No more brackets. Reviews wrap while you type, and use the same reading-font
family as posted reviews so upper/lowercase letters are clear. The review
box shows six lines before scrolling. The version field uses that font too.
Keyboard buttons, controller focus, draft text, explicit newlines, the 4,000
byte review limit, sign-in checks and the existing save action are retained.
Soft wrapping never changes the text submitted to the server.

This is not a website/backend update, SDK change or gameplay change. Existing
1.0.8 release archives, signatures and the frozen source capsule stay intact.
1.0.9-dev is a development compile label, not a published stable release.

Use the prepared private inputs and verified frozen source capsule described
in patches/release-prep/v1.0.7/BUILDING.txt. Configure an existing platform
toolchain cache with this command as one line (Windows paths or WSL paths):

  python -B patches/review-editor/configure109.py --build <platform-build>
    --capsule <verified-capsule> --log <new-evidence>/configure.log
    --cmake <cmake-executable>

The outer ReleaseOverlay composes AFTER all accepted layers and the existing
startup memory hotfix. It replaces only the final launcher translation unit
and ImGui widgets translation unit. Counted anchors stop configuration if
their expected sources change. A build-local JSON receipt records input,
authoring and output hashes. Protected checkouts and generated guest code
are never edited. Do not edit/rebaseline the old capsule for this feature.

ImGui 1.90.4 has no editable word-wrap flag. A scoped, review-only wrapper
therefore shares one visual-row layout between text drawing, cursor, mouse
selection, Home/End, Up/Down and PageUp/PageDown. Native input, paste, undo,
IME and UTF-8 storage remain in use. Scrollbar width is reserved immediately
so line breaks do not jump when a longer review starts scrolling. Other
inputs continue through the unmodified upstream branches.

Compile/source inspection only has been performed, not gameplay/UI execution.
Owner checks: selected-rating highlight, long words, paragraphs, changing
window width, mouse selection, keyboard editing, controller/Keyboard modal,
Keep for later, edit existing review, and posting the intended rating/text.
No release packages, remote pushes, uploads or signing changes are implied.
When packaging later, include Windows and Linux AppImage variants as usual.
