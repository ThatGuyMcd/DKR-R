DKR-R 1.0.9 - Online lobby repair playtest 9
==========================================

Please use this fresh package on EVERY PC in the lobby. Don't mix it with
Playtest 8 or copy just the main executable over an older install. Existing
personal saves and installed content stay in their normal locations.

This repairs the party lobby, not the game simulation or renderer:

* Every lobby port now has its correct slot number, even when vacant. Two-
  and three-player lobbies no longer send empty/invalid settings packets.
* Launch uses the protocol's valid committed stage 1. The host checks that a
  descriptor can be encoded before starting; no more empty stage-2 launches.
* Ready waits for the client's current authenticated roster and Rollback
  settings. Current Ready/automatic-delay updates are reflected correctly.
* The host requires a completed two-way heartbeat and recent traffic from each
  remote racer before starting. Spectators still do not take controller ports
  or block racers.
* Promoting an approved join keeps one sequence/nonce counter. The acceptance
  packet cannot collide with the first authenticated heartbeat/roster update.
* Duplicate acceptance packets do not reset an admitted client's port/phase.
* A failed connection stays failed instead of being projected back into an
  apparently live lobby. Delayed packets cannot revive it or repeat timeouts.
* Native lobby/diagnostic registries now outlive session shutdown. This fixes
  the exit/restart crash identified in the supplied host and client logs.

The existing lobby design, invites, spectators, player swaps, online content
and Rollback-aware connection check remain. Once everyone has joined and the
lobby settings have synchronized, the host can use Check Rollback connection.
No graphics, save data, guest simulation, mods or physics have been changed.

VALIDATION
Compilation/linking and static source/binary/archive inspection only. The game,
mods, test executables and AppImage have NOT been launched. Real-network and
gameplay testing remain yours. Nothing has been pushed, published or signed.
