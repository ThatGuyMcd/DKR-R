DKR-R v1.0.9 Release Build

This release includes the owner-accepted public lobby launcher changes:
worldwide Public/Friends browsing, signed-in account online counts, shared
Discord sign-in, and Private/Public hosting. Private rooms use friends or lobby
codes. The directory handles discovery and admission; existing peer transport
and rollback continue to run the match. The owner-deployed API service is required
for public discovery. Existing FTP mod uploads and website layout are unchanged.

Retains current spectator support, Rollback connection checks and Scoreboard,
party start/checkpoint clock/departure repairs, restored lobby layout, vehicles,
texture tools, achievements and the previously accepted presentation/runtime
changes. Running spectator entry remains controlled by its separate service flag.

Windows x64, Linux x86_64 and ARM64 AppImages, Steam Deck and Android ARM64.
The Steam Deck download uses the exact Linux x86_64 payload. Existing Apple
source compile-check workflows do not produce macOS/iOS release packages.

Use matching complete v1.0.9 builds on all peers. Windows: extract the whole ZIP
and keep assets/libexec together. Linux: make the AppImage executable. Android:
update the existing compatible app; retain saves and the original signing identity.
Android version code: 1090001. No save reset or mod reinstall is required.

Bring your own supported US v1.0 or US Rev A/v1.1 ROM. No ROM, personal saves,
installed mod library, credentials, SDK, offline guide or private diagnostics are
included. Existing SDK/API compatibility and required legal notices are retained.

Build validation covers compilation/linking, retained source/online contracts,
architecture, dependencies, package hashes and Android signer continuity.
Hardware, controllers, native TLS/keyring behaviour and cross-platform gameplay
acceptance remain separate from compilation. No automatic-update signatures or
public release upload are implied. The prior public-lobby Windows pilot was
reported working by the owner; that is not blanket acceptance of every platform.
