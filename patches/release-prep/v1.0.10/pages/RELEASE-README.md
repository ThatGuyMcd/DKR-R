# DKR-R v1.0.10 Release Build

This update brings the working playtest 4 online fixes into the release.
Modded joins, race starts, offline mod copies and spectator picture/audio
have been improved. I've kept the current launcher design and tidied up
Open Lobbies to give the list more room.

Windows: extract the whole ZIP and open DKR-R.exe. Keep assets and libexec
with it. Linux and Steam Deck: make the AppImage executable and launch it.
Linux needs glibc 2.38, GLIBCXX_3.4.32 and a compatible Vulkan driver.

Bring your own supported US v1.0 or US Rev A/v1.1 ROM. No ROM is included.
Your existing saves, mods and settings can stay. Use matching complete
v1.0.10 packages for Online. Read RELEASE-NOTES.txt for the changes.

Windows x64, Linux x86_64/ARM64 and Steam Deck are included. Android releases
are no longer supported. There are no new macOS or iOS builds in this set.

Guides, downloads and support:
https://github.com/ThatGuyMcd/DKR-R
https://discord.com/invite/AMWfXdBjNP

Auto updates need both DKR-R-update.json and DKR-R-update.sig, signed with
the existing release key. Do not alter the files or packages after signing.
The SDK and Modding Bible are separate downloads. No offline Player Guide
is included. Keep all required licence notices with the application.
