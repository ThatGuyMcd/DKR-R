DKR-R v1.0.9 - Spectators Playtest 5

VEHICLES IN THE MOD STORE

The old Legacy / ROM hacks category is now Vehicles. Browse, installed filters,
requests, listing editing and uploads all use the same label. Existing library
IDs and hosted links are kept; nothing needs moved on the website.

Vehicle Store installs use the same importer as Import Mods. Download a car
or a vehicle ZIP, install it, then find it in Mods/Hacks / Vehicles. Its own
name and portrait are used. This installs the car, not a replacement driver.
Cars remain Track Select content, with the same offline/online selection and
rendering behaviour as manually imported cars.

Duplicate choices, installed status, update notifications, reinstall, previous
versions and removal now include vehicles. Updates keep your enabled/disabled
choice and retire only the selected old edition. Shared cars owned by another
installation and unrelated local cars are kept. Identical exports share one
native library entry, even if one download is a ZIP and another is .dkrkart.
Keep both can retain distinct car versions in the normal vehicle library.

The active library is protected by the Store transaction journal. If preparation
or publication fails, the previous installation stays recoverable. No saves,
original downloads, ROMs or vehicle authoring files are removed. Old verified
ROM-patch downloads can still be reinstalled/restored; Import Mods is unchanged.

FOR LIBRARY STAFF

Publish car listings in Vehicles. The category's internal API ID is still
legacy for compatibility. The deployed website API accepts ZIP uploads; when
you choose a standalone .dkrkart in the launcher's uploader, it wraps the exact
export in a normal vehicle ZIP automatically. This does not alter the inner
car, textures, seat anchors, LODs or package identity. Select the same source
export to resume an upload. Existing ZIP uploads work unchanged.

The importer still supports cars only. Hovercraft/plane extensions remain
reserved and receive the same unsupported-type message as manual imports.
This build does not add those vehicle types or weaken import limits.

YOUR CHECKLIST

Publish a vehicle ZIP, install from the Store, then check its card in Vehicles
and its portrait in Track Select. Restart and confirm Store status still says
Installed. Compare with Import Mods using the same export. Try a bundle, an
already-imported car, Replace & reinstall, Keep both, a disabled-car update,
restoring the previous version and removing a Store vehicle. Check that other
cars stay installed. Keep runtime.log if anything goes wrong.

RETAINED ONLINE FEATURES

Rollback remains the only sync mode. New profiles default to four racers,
14 predicted frames, manual six-frame delay, spectators enabled, replay
recording off and Development lobby off. Existing valid preferences are kept.
Development lobbies require consent, use temporary progress and pause achievements.

Spectators, live racer/spectator swaps and actionable invitations remain in
this build. Invitations ask before stopping a running game, return safely to
the launcher and retain normal mod checks before joining. Everyone in an
online lobby needs this exact build. No host migration is added.

Compiled and statically inspected only. The coding agent did not launch the
game, mods, tests or AppImage. Gameplay testing is yours. No website deployment,
mod publication or GitHub upload was performed. This is an unpublished playtest,
not a production release or a signed automatic update.
