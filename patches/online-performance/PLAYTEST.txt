DKR-R v1.0.11 Online Playtest 2

Everyone in the lobby needs this build. Windows and Linux can play together.
This is a separate test build. It does not replace the GitHub release.

- Closing a lobby now retires its directory state immediately, without
  restarting the launcher. Terminal connection failures also retire it.
- The account stays connected to DKR-R Online after closing a lobby.

- Fixed the stock menu refusing newer character/vehicle menu callbacks online.
- Gave lobby downloads and the initial checkpoint more room to transfer.
- Reduced disk flushes while downloading. Every completed file is still fully
  flushed and checked before it can be used.
- Moved racing input off the ordered lobby control channel. Input remains
  reliable, with the same ownership checks and repair history.
- Allowed one larger prepared collection to stay cached when there is enough
  memory. The cache scales down under memory pressure.
- Fixed Windows update restarts inheriting the old runtime log handle.
- Added separate setup, preparation and racing timings to the runtime log.
- Added character portraits to the installed character cards, matching vehicles.
- Moved session save/mod details below the lobby title and visibility below
  the lobby code. Smaller windows stack the sections.
- Friends now use smaller cards. Add a Friend is above Search, with the same
  filters and sorting. You can also add other players from their lobby card.
- Added profile pictures. Choose and preview a PNG or JPG, use your Discord
  picture, or keep initials. Picture sharing is optional.
- Online Profile cards have matching heights and a full-width Save button.
- The Field of View slider now updates the active offline race on the next
  game frame, including while paused. The existing online restriction remains.
- Steam Deck can remember sign-in without a desktop keyring when you choose
  Keep Me Signed In. The fallback file is readable only by your Linux user.

Profile pictures and lobby friend actions need the matching API bundle deployed.
After deploying it, sign out and back in with Discord once. This refreshes the
Discord name and image used by the optional profile prompt.

Please test a fresh join with the full mod selection, then leave and rejoin.
Try a stock race, a custom race, track changes and a lobby with a spectator.
Keep offline mod copies enabled. Save runtime.log from every machine if
anything goes wrong, along with Copy Join Diagnostics from the joining client.

The automated checks use synthetic worlds and package data. Actual online
gameplay and the improvement on your connections still need testing.
