DESIGN SYSTEM

A visual QA reference for the launcher. The document is organized by foundations, control families, reusable components and composed patterns so differences in scale, spacing, borders, states and interaction behavior can be compared directly.

Reading order: start with the shared visual foundations, compare primitive controls across features, then inspect composed Sound and Online patterns. Product specimens below keep their original classes and assets.
