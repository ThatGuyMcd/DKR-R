# v1.0.12 documentation update

I've updated the current README, launcher/Online/profile, graphics, build,
platform and update guides for v1.0.12. The public notes cover everything since
v1.0.11 without turning the changelog into a list of internal implementation details.

Older release notes, validation records, addon/format versions, frozen source,
licences and contributor credits keep their original meaning. The existing
release recipe stays at its baselined path; it now reads VERSION and includes
the accepted final profile/online layers. No extra patch layer was added.

The release handoff includes the documentation inventory, local-link checks,
source comparison and exact package checks. Automated results and physical
device/multiplayer checks are recorded separately in [release validation](../RELEASE-VALIDATION.md).
