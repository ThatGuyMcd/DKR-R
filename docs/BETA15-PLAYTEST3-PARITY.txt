LOCAL SETTINGS REQUIREMENT / REMAINING WORK
No host camera/scenery settings or individual category sound gains are imposed
on clients. Preferences are left intact. Renderer settings, HUD layout and master
output volume remain local.

Full independent Camera & Scenery and per-category sound-gain parity is NOT
finished. Those existing hooks alter checkpointed guest/audio state; applying
each peer's preferences there would desynchronize replay. The experimental CPU
still uses canonical defaults for those hooks. They need a separate render/output
implementation before they can safely work independently. This package does not
claim otherwise and is not completion of the entire parity roadmap.

The earlier out-of-range guest-address report in alAdpcmPull is also NOT proven
resolved. Detailed failing address/register/source diagnostics are retained;
the supplied older log lacks that information. The memory safety fence is not
disabled or replaced with guessed audio data. Send a new runtime.log if it recurs.
