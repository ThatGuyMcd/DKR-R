# v1.0.10 documentation update

I've updated the current guides for the accepted playtest 4 fixes and the
v1.0.10 release. The README keeps the Mod Store link added on GitHub.

The changes cover modded lobby joins, retries, offline copies, race starts,
spectator picture/audio, the tidier Open Lobbies layout, supported downloads
and signed updates. Android releases are no longer supported. Mac and iOS
are skipped for this release.

Old changelog entries, playtest notes, platform investigations and validation
records keep their original versions and results. The v1.0.9 validation record
is archived separately. Version-independent format references, licences,
credits, SDK numbers and Blender addon versions keep their existing meaning.

The [release Patch Pipeline](../patches/release-prep/v1.0.10/release.py) creates
a verified source backup, applies the authored documentation and records the
before/after hashes. It checks unrelated pre-existing source remains unchanged.
The release handoff includes a documentation inventory and local-link results.
